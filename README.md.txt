# Island Airport

Casual stylized island scene for the Hypercell 3D Generalist test task.

**Unity:** 6000.3.16f1, URP (Mobile)
**Scene:** `Assets/Scenes/Island_Scene.unity`

## Theme
Small island airport with a gas station, terminal building, runway, lighthouse and beach props.

## Rules followed
- One realtime Directional Light
- No post-processing
- No baked lighting

## What I did
- Assembled the scene from the provided models, split props into prefabs
- Grouped the Hierarchy: Ground, Roads, Buildings, Props, Vegetation
- Set up materials and lighting for a soft casual look
- Camera controller: scroll to zoom, middle mouse to pan (Play Mode)
